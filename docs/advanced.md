# 进阶设置与本地部署

[返回首页](../README.md) · [首次配置](getting-started.md)

普通使用无需理解本页的实现细节。要调整会话项目、自动推进规则或本地数据目录时再看对应章节。

## 网页任务放到哪个项目

进入「个人资料 → 网页会话所属项目」，点击「选择已有项目」，选择后保存。网页创建或恢复任务时会使用对应项目与目录。未设置时使用本地状态目录下的 `workspace`；设置只保存在本机。

网页会持续使用自己的同一个 Codex 任务，运行中发送的消息会追加到当前轮次。若要改到桌面继续，先点击「移交桌面」，再在桌面重试。

## 自动推进白名单

自动推进仅适用于你允许的网站，最终提交仍要确认。在「个人资料」保存规则后，可以用「检查网站」验证目标网址是否匹配。

每行一条，匹配的是域名，不是完整网址：

| 规则 | 含义 |
| --- | --- |
| `jobs.example.com` | 只匹配这个域名。 |
| `*.example.com` | 匹配子域名，不包括 `example.com` 本身。 |
| `?` | 通配规则中的一个字符，例如 `jobs?.example.com`。 |
| `re:^jobs\d+\.example\.com$` | 使用正则表达式完整匹配域名。 |
| `*` | 所有网站；范围很宽，请只在理解含义后使用。 |

白名单不会免除执行环境权限、缺失信息和最终提交的确认，也不会绕过网站验证或使用条款。

## 本地存储与备份

默认数据目录是 `~/.job-autopilot/`，数据库是其中的 `state.db`。职位、个人资料、求职偏好、申请记录与活动进展保存在本机，不需要提交到代码仓库。

备份或迁移前，先暂停任务并停止使用这个目录的后台与插件进程，再备份整个状态目录；同时保留你自己管理的简历文件。不要在数据库仍被写入时只复制一个文件当作完整备份。

`JOB_AUTOPILOT_HOME` 可以指定另一份状态目录。例如从仓库启动一个独立的本地实例：

```bash
JOB_AUTOPILOT_HOME=/absolute/path/to/job-autopilot-data ./scripts/job-autopilot serve --port 8877
```

替换为你自己的目录。网页和 Codex 插件必须使用同一数据目录，才能共享记录；只给网页设置这个变量不会自动更改另一个进程的配置。

## 本地运行，不是公网部署

控制台默认只监听 `127.0.0.1`，适合你在自己的电脑上使用。它能访问本机资料和 Codex 能力，不是带多用户隔离的在线求职平台。

不要把控制台端口直接映射到公网，也不要把绑定地址改为 `0.0.0.0` 当作安全的远程部署方案。本项目尚未提供面向公网的完整身份验证与租户隔离方案。

网页后台没有自动开机启动的承诺。关闭网页标签不等于停止后台；停止后台或电脑休眠时，自动同步和自动更新不会执行。

## 数据会发到哪里

- **GitHub**：下载插件代码和公开职位数据，不上传个人资料、简历或投递记录。
- **Codex 与所用模型服务**：在你发起简历解析、对话和填写任务时处理相关内容。不要把「本地控制台」理解为全部离线推理。
- **招聘网站**：在登录、填写、上传和提交申请的过程中接收相应资料。
- **JDWatch**：用于已配置和授权的岗位查询，不是打开本地职位库的前提。

控制台活动摘要会尽量避免敏感信息，但模型回复和确认界面仍可能包含你本轮处理的资料。分享屏幕、截图或日志前要自行检查。

验证码不应作为可复用资料保存；证件号码也不应存入通用资料库。遇到需要此类信息的具体申请，应在对应上下文中确认处理。安全问题的报告方式见 [SECURITY.md](../SECURITY.md)。

## 实现结构

- **Skill**：定义找岗、核实信息、填写、确认与记录的工作流程。
- **本地服务与数据库**：提供控制台接口，并用 SQLite 保存职位和投递状态。
- **Codex 连接**：网页通过本机 App Server 发起和恢复任务，接收流式回复、状态与权限请求。
- **MCP 工具与界面**：给 Codex 提供记录和状态操作入口；普通网页是主要控制台，兼容的嵌入式资源不作为首次使用入口。
- **外部能力**：调用执行环境里可用的浏览器，以及按需授权的 JDWatch、Android ADB。
- **GitHub 更新**：程序更新与职位数据合并独立运行，具体保护机制见[插件更新](plugin-updates.md)和[数据同步](job-library-sync.md)。

目录与测试方法见[贡献指南](../CONTRIBUTING.md)。公开仓库只附职位数据，不附维护者本地爬虫。
