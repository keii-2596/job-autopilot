# Job Autopilot

### 让 AI 帮你找校招岗位、填写申请，投过哪里一目了然。

Job Autopilot 是一个搭配 **Codex** 使用的求职助手，自带本地网页控制台。你告诉它想找什么工作，它帮你筛选岗位、打开招聘网站、填写资料；遇到不确定的信息会问你，最终投递前由你确认。

目前内置职位库面向 **2027 届秋招**，默认筛选计算机、开发和 Agent 方向。

## 你可以少做什么

- **少重复填表**：从简历生成个人资料，你确认后复用；遇到公司的新问题，再补充并记住适用的答案。
- **少翻聊天记录**：待投、需要登录、正在填写、待确认、已投递，都放在一张表里，方便继续处理和检查重复申请。
- **少猜 AI 在干什么**：网页显示回复、运行状态和确认请求。你可以追加要求，也可以暂停任务。

## 能帮你做哪些事

| 你想做的事 | 在哪里、怎么做 |
| --- | --- |
| 找合适的校招岗位 | 在「职位库」按方向、关键词和地点筛选，再让 AI 核实官网要求；需要补充查询时可接入 JDWatch。 |
| 准备个人资料 | 在「个人资料」输入简历文件路径，让 AI 解析并生成建议，检查后确认写入。 |
| 让 AI 开始工作 | 在「概览」直接对话，或点击「帮我找岗位」「帮我投简历」「继续」；也能从 Codex 对话发起。 |
| 填写招聘网站 | 接入浏览器能力后，AI 帮你登录、填表和上传简历；缺失信息、权限请求与最终提交由你确认。 |
| 跟进每一份申请 | 在「投递记录」查看实际岗位、城市、状态和历史进展，修正记录或归档旧草稿。 |
| 获取新岗位和新版功能 | 「职位库」同步 GitHub 公开数据；「插件更新」更新程序。两者独立，也可分别开启自动更新。 |

## 快速开始

### 已经在用 Codex：让它帮你安装

在 Codex 桌面端的本地任务中，发送下面这段话：

```text
请使用 $plugin-creator，读取 https://github.com/keii-2596/job-autopilot，
将这个已有插件安装到本机的个人插件市场，不要重新创建一个插件。
检查所需环境，然后启动网页控制台，告诉我访问地址。
这一步只安装和启动，不发起真实投递。
```

这是本地安装方式，不是应用商店的一键安装。按提示检查来源并授权；安装完成后新开一个 Codex 任务，说「打开 Job Autopilot 控制台」。完整准备事项见[首次配置指南](docs/getting-started.md)。

### 想先看看界面和职位库：直接启动网页

需要 Git 和 Python 3.9+；以下方式在 macOS 验证。打开终端执行：

```bash
git clone https://github.com/keii-2596/job-autopilot.git
cd job-autopilot
./scripts/job-autopilot serve
```

然后打开 **[http://127.0.0.1:8765/](http://127.0.0.1:8765/)**。首次启动会自动导入随仓库提供的公开职位数据，无需先登录白瓜。保持终端运行；按 `Ctrl+C` 停止服务，下次启动仍保留本地记录。

**打开网页不等于已经接通 AI。** 浏览职位库和手动维护记录不需要 JDWatch 密钥或手机；AI 对话、简历解析需要可用的 Codex，操作招聘网站还需要浏览器能力，短信登录再按需连接 Android 手机。详见[按需配置](docs/getting-started.md#按需配置)。

## 第一次使用，照着这四步来

1. **准备资料**：进入「个人资料」，填写简历的本机完整路径，点击「AI 解析简历」。查看解析进展，核对候选字段后确认写入，再补上求职城市和岗位偏好。
2. **先找岗位**：在「职位库」筛选，或在「概览」发送「帮我找上海、杭州的 2027 届 Agent / 后端正式校招岗位，排除实习，先列出候选，不投递」。
3. **选好再推进**：告诉 AI「处理我选中的这些岗位，帮我填到最终提交前，等我确认」。它会核实招聘官网，并在需要登录、补充信息或授权时提示你。
4. **确认并跟进**：检查公司、实际岗位、城市和申请内容，确认后再提交。随后到「投递记录」查看结果；下次点击「继续」处理未完成项。

不用学专门的指令格式，直接说需求即可。网页会自动附带 Job Autopilot 工作流；从 Codex 对话使用时，也可以加上 `$job-autopilot` 明确调用。

## 它是怎么工作的

**你负责选择和确认，Codex 负责理解与操作，网页负责展示和记录。**

网页不只是展示页：接通本机 Codex 后，可以直接发起任务、追加指令和回答确认项。已安装插件的 Codex 对话也能把任务进展写入同一份本地记录，前提是使用同一个本地数据目录。

它不是无人值守的海投服务。网站规则变化、验证码、缺少资料或无法判断提交结果时，仍可能需要你接手；不能保证所有网站都能自动完成，也不保证拿到面试。

## 使用前知道这几件事

- **职位库是线索，不是实时在招保证。** 数据按 2027 届秋招标签收录，一条招聘公告可能包含多个岗位。是否符合你的届别、地点，以及是否仍接受申请，要以公司官网为准。
- **个人记录保存在本机，但 AI 处理不等于离线。** 解析和填表时，相关内容会交给你使用的 Codex 服务处理；申请时会把必要资料发送到招聘网站。GitHub 更新不会上传你的简历或投递记录。
- **自动推进不等于自动决定。** 网站白名单只控制推进范围；最终提交仍需确认。不要把密码、验证码或证件号码写进可复用资料。
- **自动更新需要后台运行。** 职位数据同步与插件更新默认都关闭自动模式；开启后每 6 小时检查。插件更新还要求受支持的本地插件安装方式，具体见[更新说明](docs/plugin-updates.md)。
