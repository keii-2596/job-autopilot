# 2027 届秋招职位快照

[`jobs.json`](jobs.json) 是从维护者本地职位库导出的公开数据，按来源标签收录 **2027 届 + 秋招或秋招提前批** 的招聘信息。当前数量以文件内容和控制台为准，更新记录可查看此文件的 Git 历史。

一条记录可能是包含多个岗位的公司招聘公告，并不等于一个已确认仍开放的具体职位。标签筛选不能替代官网核实；投递前请确认实际岗位、毕业时间要求、工作城市和截止日期。

快照只包含公司、岗位、地点、批次、学历、截止时间、公告与申请链接等公开字段，不包含个人资料、投递记录、浏览器登录信息、Cookie、验证码、活动日志或本地数据库。

仓库不包含白瓜抓取实现，也不会通过 GitHub Actions 访问白瓜。数据由本地 Job Autopilot 更新并在审核后发布。招聘状态可能变化，请以公司招聘官网为准；职位描述与链接的权利归原发布方所有。

首次启动控制台时，空职位库会自动导入随仓库提供的数据。已有职位库可在网页点击「从 GitHub 增量同步」，无需白瓜账号，且不会替换个人资料和投递记录。详见[同步说明](../docs/job-library-sync.md)。
